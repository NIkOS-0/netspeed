# netspeed

Последовательный замер скорости скачивания со своего компьютера. Скрипт несколько раз скачивает один и тот же адрес, дожидается полного ответа и печатает среднее время запроса, объём данных и скорость в МБ/с.

## Требования

Python 3.12 или новее.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .
```

На macOS и Linux активация окружения выглядит так: `source .venv/bin/activate`.

После установки доступны команда `netspeed` и запуск модулем `python -m netspeed`.

## Запуск

Адрес передаётся позиционным аргументом. По умолчанию выполняется 10 запросов строго друг за другом, без паузы между ними.

```powershell
netspeed "https://picsum.photos/id/1015/4000/4000"
```

Пример с паузой, другим числом запросов и отброшенным прогревом:

```powershell
netspeed "https://picsum.photos/id/1015/4000/4000" -n 10 -c 0.5 --warmup 1
```

Перенаправления проходятся автоматически. Пример отчёта:

```text
Запросов: 10 (успешно 10)
Среднее время: 1.234 с
Скачано: 25.00 МБ
Скорость: 2.03 МБ/с
```

Для скриптов есть машиночитаемый формат:

```powershell
netspeed "https://example.com/large-file.jpg" --output json
```

В примере адрес отдаёт JPEG через перенаправление. Для более устойчивой цифры укажите более тяжёлый файл.

## Как считается скорость

Каждый запрос читает тело ответа до конца. Время запроса — от старта до последнего байта. Неуспешные запросы в среднее время, объём и скорость не входят.

- среднее время — среднее арифметическое длительностей успешных запросов;
- объём — сумма реально прочитанных байт, а не заголовок `Content-Length`;
- скорость — `(сумма байт / 1 000 000) / сумма длительностей`.

Мегабайт здесь десятичный: 1 МБ = 10^6 байт. Пауза `--cooldown` в скорость не входит и после последнего запроса не делается. Запросы `--warmup` выполняются, но в отчёт не попадают.

## Параметры

Флаг командной строки перекрывает переменную окружения, переменная перекрывает значение по умолчанию.

| Флаг | Окружение | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `url` | — | обязательно | Адрес файла |
| `-n`, `--requests` | `NETSPEED_REQUESTS` | `10` | Число запросов в замере |
| `-c`, `--cooldown` | `NETSPEED_COOLDOWN` | `0` | Пауза между запросами, секунды |
| `-t`, `--timeout` | `NETSPEED_TIMEOUT` | `30` | Таймаут одного запроса, секунды |
| `--connect-timeout` | `NETSPEED_CONNECT_TIMEOUT` | как `--timeout` | Таймаут установки соединения, секунды |
| `--warmup` | `NETSPEED_WARMUP` | `0` | Сколько первых запросов отбросить |
| `--output` | `NETSPEED_OUTPUT` | `text` | `text` или `json` |
| `--user-agent` | `NETSPEED_USER_AGENT` | `netspeed/0.1.0` | Заголовок User-Agent |
| `--on-error` | `NETSPEED_ON_ERROR` | `fail` | `fail` останавливает прогон, `skip` пропускает сбой |

Коды выхода: `0` — замер завершён, `1` — запрос не удался в режиме `fail`, `2` — неверные аргументы или переменные окружения.
